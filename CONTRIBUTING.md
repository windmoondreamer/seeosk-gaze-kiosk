# Contributing

1. Create the pinned Python environment from `requirements.lock.txt` with `uv`.
2. Run `python3 build.py` on macOS to build SeeOSK.app.
3. Keep source changes under `native/`, `engine/`, `web/`, and `tests/`.
4. Do not commit camera footage, calibration profiles, or personal logs.

See `README.md` for current limitations and setup notes.
